# Learning path for a multi-cloud CI/CD setup

## 1. Foundation

Learn:
- Git and GitHub
- Linux shell basics
- YAML syntax
- environment variables

## 2. App development

Learn:
- Python web apps
- REST APIs
- health checks
- dependency management

## 3. Containerization

Learn:
- Dockerfile structure
- image layering
- local image builds
- Docker Compose

## 4. CI/CD

Learn:
- GitHub Actions
- job matrixes
- build stages
- artifact publishing
- deployment approvals

## 5. Cloud infrastructure

Learn:
- Azure resource groups and ACR
- GCP projects and Artifact Registry
- IAM and service accounts
- networking and ingress

## 6. Infrastructure as Code

Learn:
- Terraform init, plan, apply
- variables, outputs, modules
- state management
- drift detection

## 7. Production readiness

Learn:
- secrets management
- observability and logs
- rollback and canary releases
- cost management

## 8. Real-world progression

A good path is:
1. Build an app locally
2. Add tests and Dockerfile
3. Add GitHub Actions CI
4. Add Azure deployment
5. Add GCP deployment
6. Add Terraform and environment secret configuration
7. Add observability and rollbacks

This repo is meant to make that progression tangible.
